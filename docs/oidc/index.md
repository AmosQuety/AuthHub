# OpenID Connect (OIDC) Guide

AuthHub implements core OIDC features: discovery, JWKS, ID Tokens, and UserInfo.

Discovery

- `GET /api/v1/oidc/.well-known/openid-configuration` returns OIDC metadata including endpoints and supported features. See `backend/src/modules/oidc/controller.ts`.

JWKS

- `GET /api/v1/oidc/.well-known/jwks.json` returns the JSON Web Key Set with the public signing key. The `kid` is computed deterministically from the JWK thumbprint (RFC 7638) so it remains stable across restarts until key rotation.

ID Token

- Generated by `generateIdToken()` in `backend/src/core/crypto.ts`.
- Typical claims include: `iss`, `sub`, `aud`, `exp`, `iat`, plus `email` and `email_verified` when `email` scope is included.
- ID tokens have a 1 hour expiry in the current implementation.

UserInfo Endpoint

- `GET /api/v1/oidc/userinfo` returns `sub`, `email`, and `email_verified` for the authenticated user. The endpoint requires a valid access token (`authenticate` middleware).

OIDC vs OAuth

- OIDC is an identity layer built on OAuth 2.0. AuthHub supports `openid` scope; when requested, it emits an `id_token` and populates the UserInfo endpoint.
