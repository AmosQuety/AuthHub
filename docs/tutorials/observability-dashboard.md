# Tutorial — Observability Dashboard

This tutorial shows how to use the admin observability endpoints to build a dashboard.

Useful endpoints

- `GET /api/v1/admin/observability/summary`
- `GET /api/v1/admin/observability/stats`
- `GET /api/v1/admin/observability/funnel`
- `GET /api/v1/admin/observability/heatmap`
- `GET /api/v1/admin/observability/risk-trends`

What to display

- Total users
- Active sessions
- Today's logins
- Blocked or anomalous logins
- Session and login trends over time
